# 철학으로 오늘 읽기

철학자의 관점을 오늘의 문제와 연결하고, 독자가 자기 삶을 돌아보며 한 가지 선택을 하도록 돕는 카드뉴스 시리즈입니다. 10대부터 40대까지 철학을 처음 접하는 독자도 이해할 수 있는 일상적인 문장을 사용합니다.

## 현재 제작 기준

- 한 회차에 인물 한 명, 주제 하나, 카드 5장.
- 규격은 1080 × 1350px, 한국어 원고.
- 기본 말투는 T: 짧고 단호한 질문과 건조한 관찰. 독자를 비난하거나 조롱하지 않습니다.
- 흐름은 질문 → 두 가지 상태 돌아보기 → 실천 제안 → 판단 기준 → 오늘의 선택.
- 빈티지 판화풍 인물 이미지와 크림·적갈색·차콜 팔레트를 사용합니다.
- 인물의 실제 관점과 현대적 해석을 구분하고, 생계·돌봄·선택권·휴식의 가치를 함께 고려합니다.

T는 콘텐츠 말투를 구분하는 작업용 명칭입니다. 현재는 T 버전을 기본으로 제작합니다.

## 첫 회차

**세네카 — 내 시간을 선택하는 삶**

내 시간이 부족한 상태와 시간이 있어도 자동으로 흘려보내는 상태를 돌아보고, 내가 중요하게 여기는 것에 시간을 쓰고 있는지 묻습니다. 40–60분은 이 콘텐츠의 실천 제안이며 세네카가 정한 수치가 아닙니다.

[Figma 완성본 보기](https://www.figma.com/design/1PGaKwwmMPSHM5R4dvJGfb?node-id=733-6536)

## 새 회차를 만드는 순서

1. [공통 제작 명세](PRODUCT_TEMPLATE.md)를 읽고 인물·주제·핵심 메시지를 정합니다.
2. 명세의 **5절 회차 입력 템플릿만** 복사해 `episodes/NNN-name.md`를 만듭니다.
3. 실제 관점·인용·현대 사례의 출처와 이미지 이용 조건을 기록합니다.
4. 고정된 디자인에 원고를 배치하고, 문장 길이와 의미 단위의 줄바꿈을 조정합니다.
5. 원고와 Figma를 대조하고 검수 결과를 회차 문서에 기록합니다.

공통 규칙은 `PRODUCT_TEMPLATE.md`에서 관리합니다. 회차 문서에는 사용한 명세 버전과 해당 회차의 예외를 기록합니다. 제작물의 줄바꿈을 보존하기 위해 회차별 화면 문구는 `text` 코드 블록으로 작성합니다.
