# 철학 카드뉴스 기획서

작성일: 2026-11-02 · 상태: 방향 정리 초안

## 1. 기획 의도

철학자의 시대와 사상을 바탕으로 2026년의 현실을 바라보는 카드뉴스 시리즈. 어려운 철학을 쉬운 말과 일상적인 사례로 풀어, 독자가 자신의 삶에 연결해 이해하도록 한다.

- **주제:** 철학자 또는 철학 사상별 이야기
- **목적:** 철학을 쉽고 이해 가능하게 전달하기
- **대상:** 10대·20대·30대·40대의 철학 비전공 독자
- **핵심 메시지:** 각 철학의 특성에 맞춰 회차마다 한 문장으로 설정
- **제작 방식:** 같은 주제를 두 가지 말투로 제작. 철학적 의미와 핵심 메시지는 유지한다.

## 2. 두 가지 말투

| 구분 | 버전 1 — 다정한 F 감성 | 버전 2 — 냉소적인 T 감성 |
| --- | --- | --- |
| 기본 태도 | 독자의 마음을 헤아리며 함께 생각한다. | 당연하게 받아들인 전제를 의심하고 모순을 짚는다. |
| 말투 | 따뜻한 공감, 부드러운 질문, 다정한 설명 | 건조한 관찰, 짧고 직설적인 문장, 냉소적인 유머 |
| 전개 | 공감 → 철학적 이해 → 스스로 생각할 여지 | 통념 제시 → 모순 지적 → 판단 기준 재검토 |
| 주의점 | 위로 때문에 철학의 불편한 질문을 지우지 않는다. | 독자를 조롱하거나 인격을 공격하지 않는다. |

F·T는 콘텐츠의 말투를 구분하는 작업용 명칭으로 사용한다.

말투 비교 예시 — 특정 철학자의 발언이나 회차 메시지가 아닌 창작 예시:

- **버전 1:** “남들의 속도를 따라가느라 지쳤나요? 잠깐 멈추고, 내가 원하는 방향부터 함께 생각해봐요.”
- **버전 2:** “남의 속도를 따라가면서 그걸 내 인생이라고 부른다. 방향은 언제 확인했지?”

## 3. 카드별 흐름

**표지 → 내용 전개 → 마무리**를 기본으로 한다. 아래는 7장 구성안이며, 주제의 난도에 따라 조정한다.

| 카드 | 역할 | 담을 내용 |
| --- | --- | --- |
| 1 | 표지 | 지금의 독자가 공감할 질문이나 역설 + 철학자·사상 이름 |
| 2 | 시대적 배경 | 철학자가 살던 시대와 그가 마주한 문제 |
| 3 | 핵심 개념 | 해당 철학의 중심 생각을 쉬운 말로 설명 |
| 4 | 이해를 돕는 사례 | 일상의 장면이나 비유로 개념을 구체화 |
| 5 | 2026년 현실 읽기 | 그 철학의 관점으로 오늘의 현상과 모순을 해석 |
| 6 | 내 삶에 적용하기 | 독자가 자신의 선택을 돌아볼 질문이나 관점 |
| 7 | 마무리 | 회차의 핵심 메시지 한 문장 + 여운을 남기는 질문 |

## 4. 시대와 현실을 연결하는 원칙

- 철학자의 시대적 배경과 문제의식에 기반해 말한다. 옛 말투의 흉내보다 생각의 맥락을 우선한다.
- 2026년의 관계, 일, 경쟁, 소비, 기술 등에서 회차에 맞는 현실 소재를 고른다.
- 실제 주장·인용과 현대에 적용한 창작적 해석을 구분한다. 현대적 해석에는 “이 관점으로 오늘을 본다면” 등의 표현을 사용한다.
- 실제 인용은 출처를 확인하고, 창작한 문장을 철학자의 명언으로 제시하지 않는다. 구체적인 2026년 사건·수치를 사용할 때도 확인한다.
- 한 회차에는 하나의 중심 개념을 담고, 낯선 용어는 처음 등장할 때 풀어 쓴다.

## 5. 시각 디자인 방향

**빈티지 판화풍 그래픽 일러스트레이션**을 공통 스타일로 사용한다. 에칭의 촘촘한 해칭, 그래픽 노블의 굵은 윤곽선, 포스터의 평면적인 색감을 결합한다.

- **선:** 굵고 선명한 외곽선, 가는 선을 겹쳐 명암을 만드는 촘촘한 해칭
- **색:** 크림색·황토색·적갈색 중심의 제한된 팔레트
- **구도:** 인물을 크게 올려다보는 극적인 로우 앵글을 대표 구도로 활용
- **분위기:** 고전적이고 묵직하며, 무심하고 초연한 인상
- **시대 표현:** 인물의 복식·소품·배경에 해당 시대의 특징 반영
- **가독성:** 질감이 복잡한 그림 위에 긴 글을 겹치지 않고, 본문 공간과 대비 확보

공통 이미지 스타일 프롬프트:

> Vintage engraving-inspired illustration, bold ink outlines, dense cross-hatching, flat muted colors, graphic novel aesthetic
